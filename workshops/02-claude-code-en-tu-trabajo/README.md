# Taller 2 — Claude Code en tu día a día

Una charla para toda la empresa sobre cómo usar Claude Code en el trabajo de
cada día, y quince minutos para probarlo con una tarea de verdad. Qué es, qué
modelos hay y cuándo usar cada uno, qué es el contexto, dónde se ejecuta, cómo
pedirle las cosas y cómo ampliar lo que puede hacer.

**Duración:** unos 75 minutos (60 de charla y 15 de práctica)
**Hace falta saber programar:** no. Tampoco Git ni la terminal
**Al terminar:** habrás encargado a Claude Code una tarea de tu trabajo y sabrás
pedirla bien y revisarla

---

## Antes del día del taller

Haz la [guía de preparación](guias/00-preparacion.md). Son 10 minutos: instalar
la aplicación de Claude, descargar los materiales y comprobar que responde.

## En qué se diferencia del taller 1

El taller 1 era para construir una aplicación. Este no va de programar: va de
usar Claude Code para las tareas que ya haces (leer, resumir, comparar,
escribir, ordenar) con los documentos que ya tienes.

Por eso, en la práctica se abre **la carpeta de este taller**, no la raíz del
repositorio. Es lo mismo que harás en tu trabajo: abrir la carpeta con los
documentos sobre los que quieres trabajar.

### La práctica (15 min)

Cada persona crea una carpeta vacía (`taller-claude`, en Documentos), la abre
en Claude Code y elige una de las tres tareas. Cada tarea tiene su diapositiva
(22 a 24) con los pasos, el encargo para copiar y qué revisar, así que se puede
hacer solo con la presentación, sin descargar materiales:

- **A · Tu semana:** instala el conector de Google Calendar y, solo leyendo, le
  prepara la semana
- **B · Tus notas, en orden:** crea notas inventadas, les pone la fecha en el
  nombre y, con una instrucción escrita en un `AGENTS.md`, las resume por orden
  de fecha en una sesión nueva
- **C · Una duda, con fuentes:** busca en internet el derecho de desistimiento
  de un sofá hecho a medida y cita de dónde sale cada dato

**Quien presenta:** da una vuelta por la sala. El momento bueno es cuando
alguien encuentra un error en lo que ha hecho Claude. Ahí se entiende lo de
"revisa siempre".

## Lo que te quieres llevar del taller

- **El contexto manda.** Claude solo sabe lo que tiene delante. Lo que no le
  das, se lo inventa.
- **Pide como se lo pedirías a alguien nuevo:** quién eres y para qué, la tarea,
  el material, cómo lo quieres y cuándo está bien.
- **Revisa siempre.** Claude prepara, tú decides. El resultado lo firmas tú.
- **Nada de datos personales** de clientes ni contraseñas en lo que le das.
